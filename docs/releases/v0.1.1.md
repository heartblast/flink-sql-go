# flink-sql-go v0.1.1 릴리스 노트

- 릴리스 버전: `v0.1.1`
- 지원 Apache Flink 버전: `1.20.4`
- 지원 SQL Gateway REST API: `v1`, `v2`, `v3`
- 기준 Go 버전: `1.26.5`
- 릴리스일: 2026-07-24

## 개요

`v0.1.1`은 공개 Go module 경로를 `github.com/heartblast/flink-sql-go`로 바로잡은 첫 사용 가능 릴리스다. `v0.1.0`은 임시 module path로 게시됐으므로 사용하지 않는 것을 권장한다.

Apache Flink 1.20.4 SQL Gateway와 JobManager REST API를 JDBC, JVM, GraalVM, CGO, `database/sql` 없이 Go 표준 `net/http`로 사용할 수 있다. 런타임 외부 Go package 의존성은 없다.

## 설치

```text
go get github.com/heartblast/flink-sql-go@v0.1.1
```

```go
import (
    "github.com/heartblast/flink-sql-go/flinkrest"
    "github.com/heartblast/flink-sql-go/flinksqlgateway"
)
```

## v0.1.1 변경사항

- `go.mod` module path를 `github.com/heartblast/flink-sql-go`로 변경
- 저장소 내부 package import를 공개 module 경로로 변경
- README와 build/release 문서의 설치 및 import 예제 갱신
- source version과 배포 version을 `0.1.1`로 변경
- 지원 Flink 버전을 배포 파일의 `-flink-1.20.4` suffix와 build-info에 기록

기능 API는 `v0.1.0`과 동일하다.

## 포함 기능

- SQL Gateway REST API v1/v2/v3 session, statement, operation, result paging
- bounded `ExecuteAndWait`, channel `StreamResults`, iterator `ExecuteStream`
- `ManagedSession`, `SerializedSession`, `SessionRecipe`
- SQL 제출 결과 불명확 상태와 cleanup 오류를 보존하는 typed error
- DECIMAL 정밀도와 temporal 의미를 보존하는 타입 Decoder 및 `RowAccessor`
- identifier escaping을 적용한 Metadata Helper와 Capability API
- 복합 Primary Key와 memory bound를 지원하는 Changelog Materializer
- 독립된 `flinkrest` JobManager REST client
- context 취소, response/row/poll 제한, same-origin result URI 검증
- SQL 원문과 인증 정보를 기본 오류 및 Observer에서 제외하는 보안 정책

## 중요한 동작 정책

- SQL 제출 POST는 자동 재시도하지 않는다.
- 세션 만료 시 자동 복구 또는 SQL 자동 replay를 수행하지 않는다.
- SQL Gateway Operation cancel과 Flink Job cancel은 자동 연결되지 않는다.
- 기본 결과는 `json.RawMessage`이며 타입 변환은 호출자가 명시적으로 요청한다.
- Changelog Materializer는 Primary Key와 결과 column metadata가 모두 필요하다.

## 알려진 제한

- 실제 Flink 1.20.4 환경의 장시간 streaming, session expiry, API version별 contract matrix 검증은 별도로 필요하다.
- trusted reverse proxy용 NextResultURI rewrite resolver는 포함하지 않는다.
- 전체 fuzz suite, Linux build script, cross-platform CI, SBOM, provenance 자동 생성은 포함하지 않는다.
- Windows race detector는 C compiler가 있는 환경에서 별도로 실행해야 한다.
- 인증 방식과 사용자 권한 정책은 상위 서비스가 제공해야 한다.
